Minimum Spanning Tree using Prim's & Kruskal's Algorithm

🌳 Prim's Algorithm

Prim's algorithm starts from any vertex and grows the Minimum Spanning Tree by repeatedly selecting the smallest edge connecting a new vertex.

⚡ Kruskal's Algorithm

Kruskal's algorithm sorts all edges by weight and repeatedly adds the smallest edge that does not form a cycle until the MST is complete.
